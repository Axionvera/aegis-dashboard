**Aegis RWA Dashboard** is the official web interface for the Aegis RWA Protocol.
Built with Next.js, it provides a seamless UI for administrators to mint compliant
Real-World Assets (RWAs) on the Stellar network and for investors to monitor and
manage their on-chain portfolios — all secured through the Freighter wallet browser
extension.
